Source: `VESSEL_Claude_Handoff.txt` (last updated by founders 2 September 2026), plus founder
clarifications recorded 2 September 2026 below. This file is the corrected, current reference —
read it instead of re-deriving conclusions from the raw handoff each time.

Labels carried over from the original handoff and used consistently below:

- **CONFIRMED** — stated by founders or backed by supplier/order documents.
- **WORKING DECISION** — current direction, may still be refined.
- **MODEL ASSUMPTION** — planning input only, not real sales data.
- **RECOMMENDATION / OPINION** — advice or judgment call, not an executed decision or fact.
- **OPEN** — unresolved, still awaiting a quote, test, or founder decision.

Do not blur these categories when using this file — a financial-model assumption is not a fact,
and a product opinion is not customer data.
